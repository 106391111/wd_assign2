ScreenSpot – Movie Booking Website

PROJECT DESCRIPTION
ScreenSpot is a movie booking website developed as part of the COS10005 Web Development unit. The website allows users to browse movies, receive movie recommendations, register an account, and complete a movie booking form.

TECHNOLOGIES USED
- HTML5
- CSS3
- JavaScript

PROJECT FILES
- index.html: Home page
- movies.html: Displays the available movies
- recommend.html: Provides movie recommendations based on user selections
- register.html: Registration form with input validation
- booking.html: Movie booking form with pricing and payment options
- css/style.css: Stylesheet used to design the website
- js/script.js: JavaScript used for interactive features and form validation
- images/: Contains the movie poster images

IMAGES
The six fictional movie poster images used in this project were AI-generated for the website.

TESTING
All website pages and interactive features were tested locally in the Safari browser. Navigation, movie recommendations, registration form validation, and booking form functionality were checked. The project was tested successfully without any identified issues.
